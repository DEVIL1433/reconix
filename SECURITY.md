# Security & Responsible Use

## Authorized use only

Reconix is a dual-use security assessment tool, published for professional
testers, researchers and defenders. Use it only against systems you own or
are explicitly authorized to test (signed engagement, bug-bounty scope, or
your own infrastructure). Unauthorized scanning or exploitation may be
illegal in your jurisdiction.

## Reporting a vulnerability in Reconix itself

If you find a security issue in Reconix (the scanner, this repository, or
the Android app), please report it privately to the maintainer via GitHub
(Security → Report a vulnerability, or open an issue marked `security`
without exploit details) so it can be fixed before disclosure.

## What this repository never contains

- Scan databases or results from real engagements
- Credentials, session cookies, API keys or signing keys
- Client data of any kind

If you believe any such material has been published here by mistake,
contact the maintainer immediately.
